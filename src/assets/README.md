# Assets

## `tolon-logo.*`

The author's mark, shown in Settings → About beside the program's name.

Drop the file here as `tolon-logo.png` (or `.svg`, `.jpg`, `.webp`) and it
appears — the panel finds it with `import.meta.glob`, so no code changes and
nothing to register. Remove it and the panel simply has no logo; the build does
not care either way.

Nothing here is Amiga content. ART ships no OS, no ROM and no distribution
files, ever.
